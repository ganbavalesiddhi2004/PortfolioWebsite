# SiddhiSphere - Personal Portfolio Website

SiddhiSphere is my personal portfolio website developed to showcase my skills, projects, education, internship experience, and achievements in a professional way. The website reflects my journey as an MCA student and an aspiring Python Full Stack Developer.

This portfolio is designed using HTML5, CSS3, Bootstrap 5, and JavaScript with a responsive and user-friendly interface. It provides visitors with a complete overview of my technical skills, academic background, and practical experience.

The website includes a modern Home section with a professional introduction, an About section describing my career objectives, an Education section highlighting my academic qualifications, and an Internship section presenting my experience at Peakprosys Solution Pvt. Ltd.

The Skills section showcases the technologies I work with, including Python, Django, HTML, CSS, JavaScript, Bootstrap, MySQL, Git, and GitHub. The Projects section presents some of my major academic and personal projects such as the Attendance Tracking System, Achievers Academy Management System, and Online Campus Placement System.

The Contact section provides easy ways to connect with me through email, LinkedIn, and GitHub. The website is fully responsive and works smoothly across desktop, tablet, and mobile devices.

This portfolio represents my passion for web development and continuous learning. It demonstrates my ability to build clean, responsive, and interactive web applications while following modern web development practices.
